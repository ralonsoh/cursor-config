# List of ticket types and their hierarchy

Types of tickets:
- Feature request: umbrella ticket of an Epic.
- Epic: umbrella ticket of Bugs, Spikes and Tasks. When all these tickets are closed, the Epic can be closed too.

Particularities of each ticket:
- When a Bug is created, it is automatically created an Epic. Under this Epic, a set of Tasks can be created for analysis, coding, review, testing, etc. The Bug ticket is used by the engineers, the customer service and management to track the status.
- The Bug ticket usually has a customer case associated.
- The Bug ticket should have the "Fixed in Build" field to

Scrum planning:
- We have two teams, "Gluon" and "Quark".
- We have always an active sprint board ("Neutron Gluon 4", "Neutron Gluon 5", etc.).
- The Bug ticket are usually not added to the scrum sprint. The Bugs are added to the "Priority Bugs" sprint, that is used as a bucket for the Bug tickets.
