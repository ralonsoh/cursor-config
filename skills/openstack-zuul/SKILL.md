# OpenStack Zuul

Set of skills for working with the OpenStack Zuul CI
(zuul.opendev.org/t/openstack). Determine what the user needs, then
read **only** the matching subskill:

- **Monitor the CI jobs of a Gerrit change** (background task,
  notification when finished, one-shot status checks) →
  Read [zuul-monitor/SKILL.md](zuul-monitor/SKILL.md)

For querying historical build data (filtering by job name, result,
branch, date), use the separate `zuul-builds-query` skill instead.
